LaunchFlow v3

Includes:
- Starry-night rocket visual direction and matching icon.
- Sign up / Log in with separate local accounts.
- Each account has separate tasks, milestones, audience, campaigns and settings.
- Milestones can be added, edited and deleted.
- Dashboard, Launch Plan, Audience, Analytics and Settings remain functional.
- Mobile navigation.

Important: email/password works locally on the device. Google/Facebook buttons are included in the interface but need real OAuth provider credentials/backend before production use. LocalStorage is not production-grade authentication or cloud sync.
